# Scripts

## What are scripts?
Scripts are small text files containing instructions for the computer to run. You do not need to be a software engineer to write them. 

## Why scientists use small scripts
Instead of clicking the same 50 buttons in Excel every day, a script can do the exact same math in one second. It makes science faster and reproducible.

## Why Git is useful for scripts
If your script works perfectly on Monday, but breaks on Tuesday, Git lets you look at the exact difference between Monday's script and Tuesday's script. 

## How Git lets you see how code changed
By running `git diff`, you can see line-by-line what was added, removed, or changed. This is the ultimate undo button for your research.
