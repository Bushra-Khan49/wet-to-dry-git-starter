# How to Keep Your Research Private

GitHub Free offers unlimited private repositories. A private repository is accessible only to you and people you explicitly give access to. 

## Step 1 — Create a private repository

1. Go to GitHub
2. Click New repository
3. Enter the name
4. Select **Private**
5. Create repository

[Add screenshot of the repository visibility selector here]

⚠️ **IMPORTANT**: Do not say "No one can ever access it." Your account security matters.

We recommend:
* Strong password
* Two-factor authentication
* Never share your password
* Never share personal access tokens

## Step 2 — Share with a professor

To share your repository with a collaborator or professor:

In your GitHub repository, go to:
**Settings** → **Collaborators** / **Collaborators & teams** → **Add people**

*(Note: Exact UI wording can change over time.)*

## Step 3 — Access from multiple locations

You can sign into GitHub from the lab, home, or another computer and access the online repository, provided you have permission and appropriate institutional policies allow it.

⚠️ **IMPORTANT**: Do not use GitHub as a replacement for your institution’s required research-data storage system.
