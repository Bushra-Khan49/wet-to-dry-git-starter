# The Free University — Learn From Real Repositories

You do not need to buy a course to start exploring real scientific software. GitHub repositories can contain documentation, examples, source code, issues and discussions created by real projects.

Here are seven repositories to explore.

## 1. nf-core/rnaseq
**Link:** https://github.com/nf-core/rnaseq
**Learn:** RNA-seq analysis workflows.
**Beginner task:** Open the README and find the section explaining how the pipeline is run.
**Wet-lab analogy:** This is like reading a highly optimized, standardized protocol for a complex assay.

## 2. Biopython
**Link:** https://github.com/biopython/biopython
**Learn:** Working with biological sequences using Python.
**Beginner task:** Find an example involving FASTA files.
**Wet-lab analogy:** This is a digital toolkit, similar to a well-stocked reagent shelf.

## 3. RDKit
**Link:** https://github.com/rdkit/rdkit
**Learn:** Working with chemical structures and cheminformatics.
**Beginner task:** Open the documentation and find an example molecule.
**Wet-lab analogy:** A digital chemistry set for modeling reactions.

## 4. Manim
**Link:** https://github.com/3b1b/manim
**Learn:** Creating mathematical animations with Python.
**Beginner task:** Run or inspect one beginner example.
**Wet-lab analogy:** Like designing a beautiful poster presentation for your data.

## 5. TheAlgorithms/Python
**Link:** https://github.com/TheAlgorithms/Python
**Learn:** Programming logic through small examples.
**Beginner task:** Find one simple algorithm and explain what it does in plain English.
**Wet-lab analogy:** A recipe book of simple, foundational lab techniques.

## 6. GATK
**Link:** https://github.com/broadinstitute/gatk
**Learn:** Genomic analysis and variant-calling concepts.
**Beginner task:** Read the README and identify what GATK is designed to do.
**Wet-lab analogy:** Like learning to operate a massive, complex piece of core facility equipment.

## 7. Scanpy
**Link:** https://github.com/scverse/scanpy
**Learn:** Single-cell RNA-seq analysis.
**Beginner task:** Find the basic analysis workflow in the documentation.
**Wet-lab analogy:** A specialized microscope for looking at individual cells.

⚠️ **IMPORTANT**: Do not judge repositories only by star count. Stars can show popularity, but they do not prove that a repository is correct, safe, maintained, or suitable for your research.
