# Start Here if You Have Never Used Git

Welcome! If you are moving from a paper notebook to a digital one, this is for you.

## What is Terminal?

Terminal is a text-based way to tell your computer what to do.

**Windows:**
* Search for cmd
* Or use Git Bash after installing Git

**Mac:**
* Open Spotlight
* Search Terminal

**Linux:**
* Open Terminal from the applications menu

If you strongly prefer buttons, GitHub Desktop is also available.

## What is GitHub?

GitHub is an online place to store your digital history. 

How to create an account:
1. Go to GitHub
2. Sign up
3. Verify email
4. Turn on two-factor authentication if available

## What is a repository?

A repository, or "repo", is simply a project folder that Git watches. 

## What is clone?

**Clone** = make a working copy of a GitHub repository on your computer.

*Wet-lab analogy:* **Clone** = make a working photocopy of your lab notebook.

## What is push?

**Push** = send your committed local Git history to GitHub.

*Wet-lab analogy:* **Push** = put your recorded experiment into the secure online copy.

## What is pull?

**Pull** = bring changes from GitHub back to your computer.

*Wet-lab analogy:* **Pull** = retrieve the latest version of the lab notebook from the online locker.

## You got this. 15 minutes a day.

You will make mistakes. That is normal. You can recover from most beginner mistakes. Do not panic. Read the error first.
