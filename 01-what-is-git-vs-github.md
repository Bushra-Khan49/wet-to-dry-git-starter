# Git vs GitHub

| Feature | Git | GitHub |
|---|---|---|
| **What is it?** | Software that tracks changes | Online service for Git repositories |
| **Where?** | Your computer | Online |
| **Main job** | Record versions and history | Store, share and collaborate |
| **Example** | "What changed?" | "Where is my online repository?" |
| **Cost** | Free software | Free and paid plans |

## Wet-lab example

**Wet lab:**
Idea → write protocol → try experiment → observe failure → change protocol → try again → record result

**Git:**
Create file → edit → check changes → commit → edit again → commit again

The important idea:
Git lets you see the history of your project.
